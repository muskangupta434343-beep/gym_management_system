## Tools
- MySQL 8.x
- MySQL Workbench (or MySQL command-line client)

## Run the project
1. Open MySQL Workbench.
2. Open `gym_membership_management.sql`.
3. Execute the script from top to bottom.
4. Run the SELECT statements to view the expected outputs.
5. The project uses sample records for demonstration; update names/dates as needed.

## Main tables
- membership_plans
- trainers
- members
- payments
- attendance

The script demonstrates primary keys, foreign keys, INSERT, SELECT, JOIN, WHERE, GROUP BY, SUM, VIEW, UPDATE, and an optional DELETE statement.
